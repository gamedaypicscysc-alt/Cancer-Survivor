# Cancer Awareness Website

A responsive, multi-page website dedicated to spreading awareness about cancer, providing resources, and giving survivors a platform to share their success stories.

## Features
- **Clean URL Structure:** Every section resides in its own folder with an `index.html` file.
- **Formspree Integration:** Functional contact form and story submission form.
- **Privacy & Consent:** Story submission requires agreement to terms before publishing.
- **Bilingual Translation:** Google Translate widget supporting English and Swahili.
- **SEO & Search Engine Ready:** Includes `sitemap.xml`, `robots.txt`, and SVG favicon.

## Project Directory
- `/` - Home Page
- `/journey/` - Cancer Care Journey
- `/about-cancer/` - Information & Types
- `/success-story/` - Form to share personal stories
- `/testimonials/` - Approved community stories
- `/gallery/` - Community and awareness gallery
- `/resources/` - Guides and support hotlines
- `/contact/` - Contact page

## Setup & Deployment
1. Replace `YOUR_FORMSPREE_ID` in `contact/index.html` and `success-story/index.html` with your actual Formspree form endpoint ID.
2. Replace `https://yourdomain.com` in `sitemap.xml` and `robots.txt` with your live website domain or GitHub Pages link.
3. Host on any static web host such as GitHub Pages, Netlify, or Vercel.
